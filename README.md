
# NoteNest — Your Thoughts, Organized

A simple, modern, and personalized note-taking web application designed to help you organize your thoughts, manage daily tasks, and keep important ideas in one place.

## About the Project

NoteNest is a personal productivity application built with HTML, CSS, and JavaScript. It provides a clean workspace where users can create, edit, search, organize, and manage notes through an easy-to-use interface.

The project focuses on practical functionality, responsive design, and browser-based data storage without requiring an account or a backend server.

## Features

- **Create & Edit Notes** — Write, update, and save personal notes.
- **Categories** — Organize notes into Personal, Study, Work, and Ideas.
- **Favorites & Pinning** — Keep important notes easy to find.
- **Search** — Find notes by title, content, category, and tags.
- **Archive & Trash** — Keep the workspace organized and restore deleted notes.
- **Checklists** — Create task lists and track completed items.
- **Custom Note Colors** — Choose colors to distinguish your notes.
- **Dark & Light Mode** — Switch between display themes.
- **Sorting** — Sort notes by title, creation date, or recent updates.
- **Grid & List Views** — Change how notes are displayed.
- **Backup & Restore** — Export and import notes through JSON files.
- **Workspace Settings** — Customize your display name and preferences.
- **Keyboard Shortcuts** — Use shortcuts to access common actions.
- **Local Storage** — Keep notes saved in your browser.

## Built With

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/taimoonislam/NoteNest.git
```

### 2. Open the Project

Open the project folder in Visual Studio Code.

### 3. Run the Application

Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

No database or backend setup is required.

## How to Use

1. Open NoteNest in your browser.
2. Click **New note** to create a note.
3. Add a title, content, category, color, and optional tags.
4. Save the note and manage it from your workspace.
5. Use search, favorites, pinning, archive, and checklists to organize your notes.
6. Open Settings to manage your preferences.
7. Export a JSON backup to keep a copy of your notes.

## Data Storage

NoteNest uses browser Local Storage to save notes and application settings.

**Important:** Notes are stored locally in the browser and are not automatically synchronized across devices. Clearing browser storage may remove saved notes, so export regular backups.
